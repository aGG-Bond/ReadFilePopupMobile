ReadFilePopupMobile

移动端文件预览组件，支持 PDF、富文本、引用文本等多种文件类型。内置 XSS 防护、强制阅读弹窗、Tab 切换等功能。

PDF 富文本 XSS 防护 移动端适配 UMD / ESM

安装

通过 npm 安装：

bash 
npm install @aggbond/my-file-preview-mobile

ES Module 引入

本插件仅提供 ES Module 格式，使用 import 引入：

js 
import FilePreview from '@aggbond/my-file-preview-mobile';

const preview = new FilePreview({});
preview.loadFile({
  name: '用户协议',
  file_type: 1,
  content_text: '<h2>用户协议</h2><p>协议内容...</p>'
});

基础预览

通过 loadFile() 方法加载文件。支持传入路径字符串或文件对象，不指定 file_type 时自动判断类型。

js 
const preview = new FilePreview({});

// 通过 URL 加载
preview.loadFile('https://mozilla.github.io/pdf.js/web/compressed.tracemonkey-pldi-09.pdf', 'PDF 文档');

// 通过文件对象加载（自动判断类型）
preview.loadFile({ pdf_url: 'https://example.com/doc.pdf' });

基础强制阅读

通过 coerceReadList 配置强制阅读弹窗，用户必须逐个阅读文件后才能操作。

js 
const preview = new FilePreview({
  coerceReadList: {
    titleText: '请阅读以下文件',
    fileList: [
      {
        name: '用户协议',
        file_type: 1,
        content_text: '<h2>用户协议</h2><p>欢迎使用我们的服务...</p>'
      },
      {
        name: '隐私政策',
        file_type: 1,
        content_text: '<h2>隐私政策</h2><p>我们重视您的隐私保护...</p>'
      }
    ],
    btnArr: ['同意并继续', '拒绝'],
    coerceCallBack: (control, buttonIndex) => {
      if (buttonIndex === 0) {
        if (control.isLastFile()) {
          alert('已完成所有文件阅读！');
          control.close();
        } else {
          control.next();
        }
      } else {
        control.close();
      }
    }
  }
});
preview.openCoerceReadPopup();

延迟配置

通过 delayConfig 设置按钮倒计时，文件加载完成后开始计时，倒计时结束前按钮不可点击。

js 
const preview = new FilePreview({
  coerceReadList: {
    titleText: '请阅读以下文件',
    tipsText: '倒计时结束后才能点击同意',
    fileList: [
      { name: '用户协议', file_type: 1, content_text: '<h2>用户协议</h2><p>协议内容...</p>' }
    ],
    btnArr: ['同意', '拒绝'],
    delayConfig: {
      seconds: 5,
      buttonIndex: 0,
      text: '请阅读 {seconds} 秒'
    },
    coerceCallBack: (control, buttonIndex) => {
      if (buttonIndex === 0) {
        alert('已同意！');
        control.close();
      } else {
        control.close();
      }
    }
  }
});
preview.openCoerceReadPopup();
实时预览
参数说明：seconds 为延迟秒数，buttonIndex 为延迟作用的按钮索引，text 中 {seconds} 会被替换为剩余秒数。

PDF 渲染模式

通过 useCanvasRender 控制 PDF 渲染方式。

值说明
trueCanvas 渲染（默认，适合移动端）
falseiframe 渲染
'auto'自动检测（移动端 Canvas，桌面端 iframe）
js 
// Canvas 渲染（默认，适合移动端）
new FilePreview({ useCanvasRender: true });

// iframe 渲染
new FilePreview({ useCanvasRender: false });

// 自动检测
new FilePreview({ useCanvasRender: 'auto' });

PDF.js 版本选择

通过 pdfJsPath 和 pdfWorkerPath 指定 PDF.js 版本。未指定时默认从 CDN 加载 pdfjs-dist@6.2.108。

js 
// 兼容旧版 iOS（如 iOS 10.3+），使用 v3 legacy
const preview = new FilePreview({
  useCanvasRender: true,
  pdfJsPath: 'https://cdn.jsdelivr.net/npm/pdfjs-dist@3.11.174/legacy/build/pdf.js',
  pdfWorkerPath: 'https://cdn.jsdelivr.net/npm/pdfjs-dist@3.11.174/legacy/build/pdf.worker.min.js'
});

preview.loadFile({
  name: 'PDF 文档',
  file_type: 2,
  pdf_url: 'https://mozilla.github.io/pdf.js/web/compressed.tracemonkey-pldi-09.pdf'
});

安全配置

通过 allowLinksAndImages 控制是否允许富文本中的链接和图片标签。

js 
// 默认模式：过滤 a/img 标签
new FilePreview({});

// 允许链接和图片
new FilePreview({ allowLinksAndImages: true });
安全提示：开启 allowLinksAndImages 时，请确保富文本内容来源可信，避免 XSS 风险。

控制对象

在 coerceCallBack 回调中接收的 control 对象，提供以下方法：

方法说明
control.next()下一个文件
control.prev()上一个文件
control.close()关闭弹窗
control.goTo(index)跳转到指定索引
control.isLastFile()是否为最后一个文件
control.getCurrentIndex()获取当前索引
control.getFileList()获取文件列表
control.setButtonTitles(titles)设置按钮标题
control.setCheckboxChecked(checked)设置复选框状态
control.isCheckboxChecked()获取复选框状态
control.getVisitedIndices()获取已访问的索引列表
control.switchTab(index)切换到指定 Tab
control.getCurrentTabIndex()获取当前 Tab 索引
