📄 Canvas 渲染 Demo

ReadFilePopupMobile v1.0.4 - 基于 PDF.js 的移动端优化方案

✨ 新功能说明

v1.0.4 Canvas 渲染模式优势：

  • 彻底解决移动端 PDF 下载问题（微信、iOS Safari 等）
  • 支持触摸滚动和缩放操作
  • 自动检测移动设备并切换渲染模式
  • 保持与原有 iframe 模式的 API 兼容
  • 加载进度条显示，提升用户体验
🧪 测试用例
Canvas 模式配置示例：
import FilePreview from '../dist/ReadFilePopupMobile.es.js'; const filePreview = new FilePreview({ useCanvasRender: true, // 强制使用 Canvas pdfJsPath: 'https://cdnjs.cloudflare.com/ajax/libs/pdf.js/3.11.174/pdf.min.js', pdfWorkerPath: 'https://cdnjs.cloudflare.com/ajax/libs/pdf.js/3.11.174/pdf.worker.min.js', canvasRenderOptions: { scale: 1.5, enableZoom: true, loadingBarColor: '#29AEEF' } });

⚠️ 使用前准备

1. 本 Demo 使用 ES Module 版本（包含完整 Canvas 功能）
2. PDF.js 库通过 CDN 自动加载，无需本地部署
3. 建议在真实移动设备上测试以获得最佳体验
4. 微信内置浏览器、iOS Safari 等环境推荐使用 Canvas 模式
